# LLM From Scratch — Easy-to-Understand Notes

Welcome to my learning journey of understanding **Large Language Models (LLMs)** from first principles.

This repository contains **structured, beginner-friendly notes** that I've created while studying how modern LLMs work. Rather than treating LLMs as black boxes, these notes aim to build intuition from the ground up starting with the fundamentals and gradually progressing to complete transformer based language models.

The goal is to make complex concepts **easy to understand**, whether you're a student, engineer, or someone curious about how models like GPT actually work.

## 📚 Topics Covered

* Tokenization
* Embeddings
* Positional Encoding
* Self-Attention
* Multi-Head Attention
* Transformer Architecture
* Feed-Forward Networks
* Training Pipeline
* Inference & Text Generation
* Fine-Tuning
* And much more as this repository continues to grow.


> **Note:** This is a living repository. I'll continue improving these notes, adding code implementations, diagrams, and new topics as I progress in my learning journey.
